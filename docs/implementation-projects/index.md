## Naming Rules

- Use matching numbered prefixes: `implementation-XX-plan.md`, `implementation-XX-tracker.md`, and `implementation-XX-verification-contract.md`.
- Add `implementation-XX-decisions.md` when decisions accumulate.
- Use `implementation-XX-seams/` for seam-specific handoffs.
- Use `implementation-XX-evidence/` for command output summaries, screenshots, logs, or other validation evidence.
